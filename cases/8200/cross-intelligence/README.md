## Evidence labels

DIRECT = source explicitly links the person and organization.

INSTITUTIONAL = source links organizations, not the individual.

CORROBORATED = supported by independent sources.

DERIVATIVE = source repeats another source.

INFERRED = analytical possibility only.

UNRESOLVED = evidence does not close the link.

## Current boundary

The laboratory does not identify deliberately anonymized officers through inference.

The absence of a located public source is recorded as a search result, not proof that a relationship never existed.
