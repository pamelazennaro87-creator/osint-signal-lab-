# Cross-Intelligence Attribution Conflicts

## Why this matters

Public records frequently reuse single-letter designations. The same designation must never be treated as a unique identifier.

This is a high-value negative control for the investigation.

## Other attribution boundaries

Do not transform:

- same designation → same person
- same rank → same person
- same appointment cycle → personal relationship
- same intelligence organization → same career path
- institutional cooperation → individual participation

## Disputed operational attribution

Public reporting can assign the same operation, capability, or outcome to different intelligence organizations.

For every disputed attribution:

1. identify the earliest located claim;
2. identify the organization named by each source;
3. map source genealogy;
4. check official confirmation or denial;
5. distinguish capability evidence from actor-identification evidence;
6. preserve unresolved status where the evidence does not close the attribution.

**Institutional attribution is not person-level attribution.**
