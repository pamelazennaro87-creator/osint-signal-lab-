# Arabic LLM Capability Layer (SIGINT → Foundation Model)

**Status:** SECONDARY + PUBLIC STATEMENT (ex-officer)  
**Layer:** Data corpus → model training → intended insight/query capability  
**Boundary:** Capability description only. No claim that any specific current officer runs the project.

## Public claim

Reporting (Guardian / +972 / Local Call, Mar 2025) describes Unit 8200 training a large language model on large volumes of **intercepted Arabic** (Palestinian and related dialects) phone and text data, with the aim of a chatbot-like tool for querying and analysing monitored populations.

## Direct public statement

**Chaked Roger Joseph Sayedoff** (former intelligence official, later Co-Founder & CEO of Specific AI) stated in a public military AI conference talk in Tel Aviv that the effort sought “the largest dataset possible” and “all the data the state of Israel has ever had in Arabic,” requiring “psychotic amounts” of data. He described early exploration of generative AI for intelligence tasks after ChatGPT’s public release.

## Chain (institutional, not personal)

```
Mass SIGINT collection (calls/texts)
    → long-term storage (documented on Azure; later relocation pressure)
        → training corpus for Arabic LLM
            → intended query / insight layer over monitored data
```

This sits **between** the archive story (Azure) and the targeting-systems story (e.g. Gospel / related tools). It is a distinct capability layer: language model as interface to SIGINT-derived data.
