# Case 004 — Analysis Framework

## 1. Recruitment surface

Classify the first observable contact as:
- employment advertisement;
- messaging-group post;
- social-media contact;
- intermediary referral;
- in-person approach;
- unknown.

## 2. Vulnerability

Record only what the source actually establishes:
- financial distress;
- unstable employment;
- migration status;
- homelessness;
- criminal marginalisation;
- ideological motivation;
- coercion/blackmail;
- unknown.

Do not infer vulnerability from appearance, nationality or occupation.

## 3. Task attribution

Separate:
- advertised task;
- completed task;
- alleged task;
- task described by investigators;
- task independently corroborated.

## 4. Controller attribution

Use an explicit ladder:

**Unknown → criminal intermediary suspected → network attributed → state-linked actor attributed → state direction independently corroborated**

The ladder is claim-specific.

## 5. Incentive

Possible documented incentives:
- money;
- cryptocurrency;
- ideological motivation;
- coercion;
- family pressure;
- status;
- unknown.

No incentive should be inferred without evidence.

## 6. Negative space

Record missing edges explicitly:

`advertisement → recruiter`

`recruiter → controller`

`controller → state`

`state → operation`

A missing edge is not permission to fill the gap with inference.

## 7. Key research question

The strongest portfolio finding may not be “who did it”.

It may be:

> **How much of the recruitment-to-command chain can public evidence actually establish?**

That is the investigative object.
