# Case 005 — RIS Network (US–EU Bridge)

## Research question

How does the publicly charged **Russian Intelligence Services (RIS) Network** in *United States v. Khrameev et al.* (SDNY, unsealed Sep 2026) connect to European sabotage and recruitment cases without collapsing distinct operational graphs into one?

## Why this case exists

Case 004 maps **European disposable-agent / recruitment** fragments (Ramagoza field graph, Eurojust parcels, judicial clusters).  
Case 005 isolates the **US primary charging document** as its own evidence object and tests only the edges that the indictment (and independent court records) actually support.

This prevents:
- treating every European arson as RIS Network activity;
- treating the RIS Network as only a European story;
- mixing parcel-graph names with Ramagoza-graph names without a primary bridge.

## Alternative hypotheses

- **H1:** RIS Network is the US charging label for a real multi-theatre structure that includes Romagoza’s EU tasking.
- **H2:** US indictment captures a subset (command + US plots); EU field cells have overlapping recruiters but separate logistics chains.
- **H3:** Media and secondary reporting over-merge Romagoza EU work with every GRU-attributed incident.

## False-confirmation tests

- Named in same indictment ≠ same cell as every LT/PL/CZ arsonist.  
- Same Cuban diaspora + Russia residence ≠ same operational tasking.  
- Crypto payment pattern ≠ single wallet or controller.  
- “GRU-linked” in LT press ≠ proof of same US RIS Network membership for field recruits.
