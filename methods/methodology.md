# OSINT Signal Lab Methodology

## Purpose

This methodology is designed for investigations where public information is fragmented, duplicated, contradictory, incomplete, or deliberately anonymized.

The goal is not to produce the most confident answer.

The goal is to produce the **most defensible answer supported by the available evidence**.

## Investigation chain

**Question → Claims → Sources → Verification → Corroboration → Contradictions → Analysis → Confidence → Limitations**

### 1. Define the question
Write the research question before collecting evidence. Avoid questions that already assume the answer.

### 2. Separate claims from facts
A source can make a claim without independently proving it. Record what the source says, what it directly establishes, and what remains inferred.

### 3. Evaluate source quality
Record publisher, date, source type, directness, institutional authority, originality, and possible source dependencies.

### 4. Corroborate
Corroboration is strongest when sources are genuinely independent. A chain such as **official announcement → newspaper → aggregator → social post** is not necessarily four independent confirmations.

### 5. Test temporal continuity
Compare designation, rank, role, unit, dates, succession context, and other legitimately public context. A compatible career path is evidence for a hypothesis, not proof of identity.

### 6. Run the false-confirmation test
> **Does this source actually identify the same individual, or does it merely describe someone with a compatible role, rank, or career path?**

### 7. Model uncertainty
- **CONFIRMED** — directly established by authoritative evidence
- **CORROBORATED** — supported by independent evidence
- **INFERRED** — analytical connection, not directly established
- **UNRESOLVED** — insufficient evidence
- **CONTRADICTED** — credible evidence conflicts with the claim

### 8. Report limitations
Every conclusion must state what the evidence cannot establish.

## Identity Entropy Reduction

For identity research, the laboratory may track how evidence reduces the set of plausible candidates without publishing an identity.

Example:

**100 → 31 → 12 → 4 → 4**

If additional evidence stops reducing the candidate space, that plateau is itself a finding.

**IER is an analytical measure, not proof of identity.**

## Source genealogy

A different URL does not automatically mean an independent source.

Ask:
- Who published first?
- Who quoted whom?
- Did wording propagate?
- Did multiple sites copy the same institutional announcement?
- Is apparent corroboration actually derivative?

## AI handling

AI can assist with discovery, translation, classification, entity normalization, timeline construction, contradiction detection, and structured extraction.

AI output is never treated as primary evidence. Material AI-derived claims must be checked against the underlying source.

## Core rule

> **The conclusion must never be stronger than the evidence supporting it.**
