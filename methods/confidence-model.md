# Confidence Model

Confidence describes the state of the evidence, not the investigator's certainty.

## Levels

### HIGH
Multiple strong sources converge, or a primary source directly establishes the claim.

### MEDIUM
Several compatible sources support the claim, but an important direct link remains missing.

### LOW
The hypothesis is plausible but materially dependent on inference, incomplete records or indirect evidence.

### UNRESOLVED
The available public evidence does not justify choosing between competing explanations.

## Evidence status

| Symbol | Meaning |
|---|---|
| 🟢 | Directly established by strong public evidence |
| 🔵 | Strongly reported/corroborated but not primary proof |
| 🟡 | Analytical interpretation or compatible hypothesis |
| 🔴 | Unresolved / not established |

## Upgrade rule

A claim moves upward only when new evidence closes a specific gap.

## Downgrade rule

Confidence must decrease when:

- a source is shown to derive from another source;
- a contradiction appears;
- a date mismatch emerges;
- an entity collision is discovered;
- an attribution boundary is crossed;
- a primary source contradicts a secondary narrative.

## Core principle

> **Unknown is not weak evidence. Unknown is a finding about the limits of the dataset.**
